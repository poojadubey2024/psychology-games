# Psychology Games

Single-player psychology learning games, playable in the browser.

- `index.html`: home page listing all games
- `heuristics/`: Game 1, *Shortcuts of the Mind* (heuristics and schemas)
  - `data.js`: all story text, answers and psychology notes
  - `img/sN/`: story images (`1.jpg`–`5.jpg` panels, `mind.jpg`, `sheet.jpg`)

Static site, no build step. Published with GitHub Pages.
